# Visual Assets Directory — Plural Gameful River

Este directorio organiza todos los recursos gráficos y visuales del micrositio:

## Estructura de Carpetas

- **`/maps`**: Cartografía interactiva, mapas SVG del río, nodos, meandros y capas de flujo fluvial.
- **`/territories`**: Ilustraciones temáticas, cabeceras editoriales y fondos representativos para cada territorio (T1 a T5).
- **`/afluentes`**: Arte visual e imaginería representativa para los horizontes/afluentes del Delta (T5).
- **`/icons`**: Iconografía personalizada para disciplinas, fuerzas motrices, componentes ecológicos y badges de la bitácora.
- **`/diagrams`**: Diagramas del Método Plural, matriz de escalamiento, escalas micro/meso/macro/meta y marcos metodológicos.
- **`/branding`**: Logotipos, isotipos e imagotipos de "Plural Gameful River" y "Método Plural".
- **`/ui`**: Texturas de papel, tramas editoriales, gradientes fluviales y patrones ornamentales de interfaz.

## Convenciones Recomendadas
- Formatos preferidos: SVG para vectores/iconos/diagramas; WebP/PNG optimizado para ilustraciones de alta fidelidad.
- Nombres de archivo en kebab-case en minúsculas (ej: `map-river-course.svg`, `t1-hero-definition.webp`).
